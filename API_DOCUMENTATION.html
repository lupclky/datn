LockerKorea API Documentation

Developer Guide for Backend Services

Base URL: http://localhost:8089/api/v1

Authentication

Most endpoints require a Bearer Token. Include it in the header:

Authorization: Bearer <your_jwt_token>

1. Authentication & Users

POST/users/registerRegister new user

Create a new user account.

POST/users/loginLogin

Authenticate user and return JWT token.

GET/users/detailsGet User Details

Get information of the currently logged-in user.

PUT/users/details/{userId}Update User Details

Update user information.

PUT/users/change-active/{userId}Block/Unblock User Admin

Change user active status.

POST/users/forgot-passwordForgot Password

Initiate password reset process.

2. Products

GET/productsGet Product List

Get a paginated list of products.

GET/products/{id}Get Product Detail

Get detailed information of a specific product.

GET/products/searchSearch Products

Search products by keyword.

POST/productsCreate Product Admin

Create a new product.

PUT/products/{id}Update Product Admin

Update an existing product.

DELETE/products/{id}Delete Product Admin

Delete a product.

POST/products/uploads/{id}Upload Images Admin

Upload images for a product.

3. Orders

POST/ordersCreate Order

Place a new order.

GET/orders/userGet My Orders

Get order history of the current user.

GET/orders/{id}Get Order Detail

Get details of a specific order.

PUT/orders/status/{id}Update Order Status Admin

Update the status of an order.

GET/orders/revenueGet Revenue Admin

Get revenue statistics.

4. Order Details

GET/order_details/order/{orderId}Get Order Details

Get all details (items) for a specific order.

5. Cart

GET/cartsGet Cart

Get current user's cart.

POST/cartsAdd to Cart

Add an item to the cart.

PUT/carts/{id}Update Cart Item

Update quantity of a cart item.

DELETE/carts/{id}Remove Cart Item

Remove an item from the cart.
